# Stellar Burger

SPA-приложение для заказа бургеров с конструктором, авторизацией пользователей и обновлением заказов в реальном времени. Проект реализован на React с глобальным состоянием через Redux Toolkit, маршрутизацией и интеграцией с API.

## Цели проекта
- Реализовать SPA с клиентским роутингом и защищёнными маршрутами
- Настроить глобальное состояние приложения с помощью Redux Toolkit
- Подключить асинхронные запросы к API и хранение данных в store
- Реализовать авторизацию и защиту пользовательских данных
- Отработать работу с модальными окнами и динамическими маршрутами
- Реализовать обновление заказов в реальном времени

## Используемые технологии

| Категория | Решение |
|---------|--------|
| Язык | TypeScript |

## Ключевые реализации

### Роутинг
- Публичные и защищённые маршруты
- Вложенные и динамические маршруты:
  - `/ingredients/:id`
  - `/feed/:number`
  - `/profile/orders/:number`
- Сохранение активного состояния навигации на вложенных маршрутах
- Поддержка прямого перехода по URL (страница вместо модального окна)

### Глобальное состояние
- Единый `store` и `RootReducer`
- Разделение состояния на слайсы
- Асинхронные запросы через `createAsyncThunk`
- Хранение данных, полученных из API, в Redux
- Использование селекторов для получения данных в компонентах
- Состояния загрузки для улучшения UX

### Авторизация
- Регистрация и логин пользователя
- Защищённые маршруты для профиля и истории заказов
- Перенаправление на страницу авторизации при попытке оформить заказ
- Редактирование профиля с возможностью отмены изменений

### Заказы
- Лента заказов (`/feed`) доступна всем пользователям
- История заказов (`/profile/orders`) доступна только авторизованным
- Обновление заказов в реальном времени
- Подсчёт стоимости заказа на основе ингредиентов
- Отображение статусов заказов:
  - «Отменён»
  - «Готовится»
  - «Выполнен»

### Модальные окна
- Универсальный механизм модальных окон
- Закрытие по клику на оверлей и по клавише `Esc`
- Использование одних и тех же компонентов для модального окна и отдельной страницы
- Открытие модалок с синхронизацией URL
